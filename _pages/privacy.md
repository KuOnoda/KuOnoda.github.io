This website uses [GoatCounter](https://www.goatcounter.com/) to count page visits privately. There is no public visitor counter, and the dashboard requires the site owner's login.

The site sends only the page's fixed path (for example, `/publications/`) and a random request value that prevents caching. It does not send URL query strings or fragments, page titles, referrers, form contents, or screen dimensions. Requests omit cookies. No visitor cookies, persistent identifiers, or browser storage are created for this counting, and no consent banner is displayed.

GoatCounter receives the IP address and browser headers needed to process the network request. Its [Privacy Policy](https://www.goatcounter.com/help/privacy) explains that IP addresses and full browser headers are not stored in its database. This site's settings disable session tracking, individual-pageview records, and referrer, browser, operating-system, screen-size, location and language statistics. Only aggregate page counts are kept. GoatCounter's service stores data in Finland and Germany.

Global Privacy Control and Do Not Track browser signals are respected. Visitors using these signals, blocking requests, browsing offline or without JavaScript are not counted. Each visible page load sends at most one request; reloading can count again. These figures are estimates, not a count of distinct people. Local previews and embedded pages are excluded.

**Google Analytics is disabled.** It was briefly tested during setup on November 5, 2026, with an opt-in prompt. Google may retain data already received during that test; disabling collection does not delete that data. Revisiting this website removes its old Google Analytics cookies. See [Google's Privacy Policy](https://policies.google.com/privacy).

This website is hosted by GitHub Pages, which may process technical information needed to serve the site under [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Some site resources are delivered through jsDelivr, and external links have their own privacy practices.
